# 🌐 SA-RP Linggo (GTA SA-MP Live AI Translator Overlay)

[![AI Engine](https://img.shields.io/badge/AI%20Engine-Groq%20GPT%20OSS%20120B-38BDF8?style=for-the-badge)]()

**SA-RP Linggo** adalah aplikasi *overlay live translation* real-time berbasis AI khusus untuk player **GTA San Andreas Multiplayer (SA-MP)** & **CodSMP**. Aplikasi ini menerjemahkan percakapan Roleplay (*Inbound Chatlog* & *Outbound Clipboard*) secara instan dengan gaya bahasa *street slang* Roleplay yang alami dan **100% Uncensored**.

---

## ✨ FITUR UNGGULAN

* ⚡ **Super-Fast AI Engine (`openai/gpt-oss-120b`)**: Respon terjemahan kilat di bawah 1 detik tanpa delay.
* ⚡ **CodSMP & Standard SAMP Auto-Detection**: Otomatis mendeteksi file log terbaru di folder `/logs/` bagi pengguna CodSMP maupun `chatlog.txt` standar.
* 🤬 **100% Uncensored Street Slang**: Penerjemahan utuh tanpa sensor bintang pada kata-kata umpatan roleplay.
* 💬 **Inbound Live Feed (Chatlog ➔ Overlay)**: Otomatis membaca chat IC, `/me`, dan `/do` langsung di layar game.
* 📋 **Outbound Translator (Indonesian ➔ Hood English)**: Cukup tekan `CTRL+C` pada teks Bahasa Indonesia, hasil terjemahan gaya *American Hood* langsung siap di-`CTRL+V` ke dalam game.
* 🎨 **Glassmorphism HUD**: Tampilan overlay modern, *frameless*, transparan, serta mendukung mode kunci (*Click-Through* / `ALT+L`).

---

## 📥 PANDUAN INSTALASI & CARA PAKAI

1. **Download Aplikasi**:
   * Buka menu [**Releases**](https://github.com/yambuttt/SA---RP-Linggo/releases) di bagian kanan halaman repository ini.
   * Download file **`SA-RP Linggo.exe`**.

2. **Konfigurasi Awal**:
   * Jalankan `SA-RP Linggo.exe`.
   * Buka menu **Settings (⚙️)** di overlay.
   * Masukkan **Groq API Key** dan **License Key** kamu.
   * Atur jalur file chatlog (atau centang opsi **⚡ Saya Pengguna CodSMP** jika menggunakan CodSMP).
   * Klik **Save Settings**.

3. **Shortcut Keyboard Dalam Game**:
   * `ALT + L` : Toggle Lock Mode (*Click-Through* agar mouse bisa dipakai di dalam game).
   * `CTRL + C` : Menerjemahkan teks clipboard ke Bahasa Inggris Hood.
   * `CTRL + V` : Menempelkan terjemahan langsung ke chatbox game.
